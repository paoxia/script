# Repository Instructions

These instructions apply to the entire repository.

## Commit Messages

- Write commit messages in both English and Chinese.
- Use a bilingual subject, with English and Chinese separated by ` / `.
- If a commit body is included, provide equivalent English and Chinese descriptions.

Example:

```text
feat: add development CLI installers / 添加开发环境 CLI 安装支持
```

## Script Comments

- Write all script comments in English, including shell and Windows batch scripts.
- Use English for new or modified comments and translate existing non-English comments when updating scripts.
